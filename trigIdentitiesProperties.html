Vertically Opposite Angles
  • sin(-θ) = -sinθ
  • cos(-θ) = cosθ
  • tan(-θ) = -tanθ
  • cot(-θ) = -cotθ
Supplementary Angles
  • sin(π-θ) = sinθ
  • cos(π-θ) = -cosθ
  • tan(π-θ) = -tanθ
  • cot(π-θ) = -cotθ
Complementary Angles
  • sin( π 2 -θ) = cosθ
  • cos( π 2 -θ) = sinθ
  • tan( π 2 -θ) = cotθ
  • cot( π 2 -θ) = tanθ
Angles that differ by π [rad]
  • sin(π+θ) = -sinθ
  • cos(π+θ) = -cosθ
  • tan(π+θ) = tanθ
  • cot(π+θ) = cotθ

Fundamental Trigonometric Identities

Pythagorean
  • sin2θ + cos2θ = 1
  • 1 + tan2θ = sec2θ
  • 1 + cot2θ = csc2θ
Reciprocal Identities
  • tanθ = sinθ cosθ = 1 cotθ
  • secθ = 1 cosθ
  • cscθ = 1 sinθ

Angle Formulas

Angle Sum - Difference Formulas
  • sin(a+b) = sin(a) cos(b) + cos(a) sin(b)
  • sin(a-b) = sin(a) cos(b) - cos(a) sin(b)
  • cos(a+b) = cos(a) cos(b) - sin(a) sin(b)
  • cos(a-b) = cos(a) cos(b) + sib(a) sin(b)
  • tan(a+b) = tan(a)  +  tan(b) 1  -  tan(a)  tan(b)
  • tan(a-b) = tan(a)  -  tan(b) 1  +  tan(a)  tan(b)
Double-Angle Formulas
  • sin(2θ) = 2 sinθ cosθ = 2  tanθ 1  +   tan 2 θ
  • cos(2θ) = 2 cos2θ - 1 = 1 - 2 sin2θ
  • tan(2θ) = 2  tanθ 1  -  tan 2 θ
Half-Angle Formulas
  • sin( θ 2 ) = ± 1  -  cosθ 2
  • cos( θ 2 ) = ± 1  +  cosθ 2
  • tan( θ 2 ) = sinθ 1  +  cosθ

Sum - Product Formulas

Sum To Product Formulas
  • sin(a) + sin(b) = 2 sin( a  +  b 2 ) cos( a  -  b 2 )
  • sin(a) - sin(b) = 2 cos( a  +  b 2 ) sin( a  -  b 2 )
  • cos(a) + cos(b) = 2 cos( a  +  b 2 ) cos( a  -  b 2 )
  • cos(a) - cos(b) = -2 sin( a  +  b 2 ) sin( a  -  b 2 )
Product To Sum Formulas
  • sin(a) cos(b) = 12 [sin(a + b) + sin(a - b)]
  • cos(a) sin(b) = 12 [sin(a + b) - sin(a - b)]
  • cos(a) cos(b) = 12 [cos(a + b) + cos(a - b)]
  • sin(a) sin(b) = 12 [cos(a - b) - cos(a + b)]
